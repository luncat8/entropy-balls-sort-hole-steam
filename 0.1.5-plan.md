# 0.1.5 — status bar and help messages

Goal: a persistent status bar showing constant info and context-sensitive help.
No dev or implementation notes appear here; user-facing text only.

Parent: `0.1.0-plan.md`.

## Layout

- Top bar: title, current task text (0.1.3), solved counts per player (0.1.4),
  ball count, FPS.
- Bottom bar: help message line (one line, rotated on a timer or on context
  change) plus energy bars for players when two-player mode is on.
- Settings panel toggles with a key (`S`) and a button.

## Constant info

`balls: N  |  fps: 60  |  solved: P0 x  P1 y  |  energy: 0.8/1.0  0.4/1.0`

Shown always, updated once per frame from precomputed values (no DOM thrash:
update text only when the displayed string changes).

## Help messages

A small table of `{ when, text }`:

- No balls moving yet: "Drag the hole to let balls pass."
- Task active: "Keep {side} above {pct}% {category} balls."
- Two-player mode: "Hold mouse/touch to push or pull the hole."
- Energy empty: "Energy empty — wait to recharge."
- Settings open: "Settings are saved in the URL."

Rotate a default tip every 6 s when no contextual message applies. Help text is
written as if the game shipped; no references to plans or versions.

## Validation

- L1: status bar updates without flicker; help line changes with context.
- Manual pass: at 200 balls the bar stays at 60 fps update cadence; no layout
  shift when text changes length (fixed min-width).
